# Contributing

Thanks for taking an interest in Muhammad Asim's portfolio.

## Before making changes

- Open an issue first for larger changes or new features.
- Keep changes focused and test them locally before opening a pull request.
- Do not commit credentials, API keys, personal data, or environment files.
- Keep project descriptions and portfolio claims accurate; do not add placeholder achievements or certifications as facts.

## Local setup

```bash
pnpm install
pnpm dev
```

Run `pnpm build` before submitting when possible.

## Pull requests

Describe the purpose of the change, summarize the files affected, and include screenshots for visual changes. Contributions are reviewed before being merged.
