## Run locally

Requirements: Node.js and pnpm (or npm).

```bash
git clone https://github.com/MuhammadAsimdeveloper/My-Portfolio.git
cd My-Portfolio
pnpm install
pnpm dev
```

Open http://localhost:3000 in a browser. For a production build, run `pnpm build` and then `pnpm start`.
