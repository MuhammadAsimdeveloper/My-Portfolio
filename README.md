# Muhammad Asim — Developer Portfolio

An original, responsive, space-inspired portfolio built with Next.js, React, TypeScript, and CSS. This implementation is a fresh design rather than a copy of the reference repository.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Personalize

Update project links and descriptions in `app/page.tsx`. Replace the placeholder demo labels with current screenshots or deployed URLs as projects mature. Keep API keys and secrets out of Git.

## Stack

- Next.js 14 / React 18
- TypeScript
- Responsive CSS with reduced-motion support

The application source is original. Third-party dependencies retain their own licenses; review their terms before redistribution.
